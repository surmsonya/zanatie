# Tile Grid

Браузерный инструмент: загрузите фото, разбейте его на сетку ячеек, скрывайте ячейки кликом, искажайте всю сетку в перспективе, перетаскивая четыре угла, и экспортируйте PNG.

**Онлайн:** https://surmsonya.github.io/zanatie/

## Файлы

- `tiles.html` — основной инструмент (один файл, WebGL1 + Canvas 2D, без библиотек).
- `tiles-three-prototype.html` — ранний прототип на three.js (камера/видео, 3D-поворот, запись видео).
- `PLAN.md` — спецификация и решения.
- `index.html` — перенаправляет на `tiles.html`.

## Запуск локально

Сборка и сервер не нужны — просто откройте `tiles.html` в браузере.

## Деплой

Статический сайт на GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
